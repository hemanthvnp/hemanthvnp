### Projects

**[MargaMetis](https://github.com/hemanthvnp) — Route Optimization System**
A route optimization engine built in Python using the A\* algorithm with heuristic-based pathfinding. The system models real-world logistics constraints like traffic and fuel usage, and supports multi-route comparison so users can weigh trade-offs in delivery planning. This is the project where I really got comfortable with graph algorithms.
*Stack: Python, A\*, Graph Algorithms*

**[CineScope](https://github.com/hemanthvnp) — Movie Discovery & Analysis Platform**
A movie exploration platform for searching and analyzing films using external APIs. Pulls real-time data — ratings, genres, cast, trends — and surfaces it through a UI built around dynamic search and filtering. A lot of the work was on the API integration side: handling rate limits, caching responses, and keeping retrieval snappy.
*Stack: JavaScript, REST APIs, Web Development*
